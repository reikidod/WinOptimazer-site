# WinOptimizer Website Design System

Reference: approved visual concept #3.

## Tokens
- Page background: #F6FAFF
- Surface: #FFFFFF
- Hover surface: #F0F8FF
- Primary cyan: #00B4F4
- Action blue: #0078D4
- Main text: #102A4C
- Secondary text: #475F7C
- Muted text: #647C98
- Border: #DCEBFA
- Radius: 12–18 px
- Shadows: soft blue-tinted shadows; no heavy dark shadows.

## Visual direction
Light Modern Fluent Design, bright white surfaces, cyan/blue gradients, gentle background waves, subtle glass effects, compact navigation, rounded feature/statistic cards and clear download actions.

## Consistency
The website and WPF app share the same brand colors, logo geometry, icon language and component rhythm. Keep all existing anchors, analytics IDs, release links, download behavior and responsive navigation intact.
