# WinOptimizer Website

Официальный лендинг для [WinOptimizer](https://github.com/reikidod/WinOptimazer) — бесплатного инструмента настройки и оптимизации Windows 10/11.

## Стиль

Сайт повторяет тёмную тему приложения:

- Фон: `#1B1C1F` / `#2A2C31`
- Акцент: `#8AAAD8` / `#4B6CA3`
- Красный акцент из баннера: `#C0262D`

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
npx serve .
# или
python -m http.server 8080
```

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Сайт будет доступен по адресу:

`https://reikidod.github.io/WinOptimazer-site/`
