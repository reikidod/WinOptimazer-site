Возможности

Всё необходимое для комфортной работы и игр на Windows — без лишней сложности.

⚙️

Оптимизация системы

Каталог твиков реестра и служб с описаниями, оценкой пользы и предупреждениями. Исходные значения сохраняются — изменения можно отменить.

🎮

Игровой режим

Подготовка Windows к играм, обнаружение Steam, Epic, GOG и Xbox, настройки GPU и поддержка OptiScaler.

📦

Установка программ

Популярные приложения, VC++ и DirectX, дополнительные утилиты. Установка одним кликом.

🛒

Microsoft Store

Каталог приложений с иконками и установкой через winget.

🧹

Очистка и обслуживание

Временные файлы, кэши, автозагрузка и удаление ненужных приложений.

💻

Информация о ПК

Процессор, видеокарта, ОЗУ, накопители и общее состояние системы.

🎨

Персонализация

Несколько тёмных тем, цветовые акценты и настройка фона приложения.

↩️

Контроль изменений

Отмена поддерживаемых твиков и возврат сохранённых исходных параметров.

Безопасность

Откат твиков

Поддерживаемые изменения реестра сохраняют исходные значения для последующего отката.

Проверка загрузок

Установщики и библиотеки проверяются по SHA-256 там, где это предусмотрено.

Без телеметрии

Приложение не отправляет сведения о компьютере на сторонние серверы.

Открытый код

Исходный код открыт; сборки публикуются через GitHub Releases и GitHub Actions.

Перед масштабными изменениями создайте точку восстановления Windows. Не применяйте твики, назначение которых вам непонятно.
